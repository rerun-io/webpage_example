Interactive demo
Interactive Rerun demo. Note that the viewer is interactive, so you can zoom, pan, and select entities in the 3D scene. If you select an entity in the viewer, it will output the entity path under the viewer. This is achieve using the event listener that calls a callback function every time the selection changes. There are other events that can be listened to, such as, time updates, timeline changes, etc., enabling interesting dynamic interaction between the viewer and the page.
